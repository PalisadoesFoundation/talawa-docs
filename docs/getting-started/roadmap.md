Welcome to our summary product roadmap. It has changed due to the impact of Hurricane Melissa on the island of Jamaica.

## Introduction

The Talawa web/mobile app suite was designed for volunteer based organizations to organize their memberships. 

The apps have:

1. news feeds,
2. group chats, 
3. volunteer management for events, 
4. member management, 
5. skills management by tagging members and possibilities for 
6. local advertising
7. A backoffice admin panel.
8. A plugin system that supports volunteer donations. 

Talawa is also designed to handle multiple organizations with a single API end point.

We plan to start using our alpha MVP internally for use by our own volunteers before the end of 2025.

## Disaster Management Features

We feel that Talawa can easily be adapted to have new features to assist with disaster relief coordination by independent non-profits. These features will be added as part of our product roadmap for implementation in mid to late 2026.

### How You Can Help - Melissa

If you are a software developer and want to make a tangible contribution to a long term project to assist non-profits in both Jamaica and other countries manage their volunteer membership and with features for better community engagement, then you have come to the right place.

Based on your experience with this or other disasters we are looking for:

1. ideas for this feature set
2. ways to make existing code more modular and reliable


We have an international coder base. If your IT teams are interested please jump in. The faster we can dogfood this better.

We want to re-emphasize that this is not for immediate implementation, but with tweaking there could be opportunities for a phased implementation starting with an IT heavy user base.
