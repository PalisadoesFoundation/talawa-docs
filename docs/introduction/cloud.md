The choice is yours.

1. Your cloud
2. Any hybrid cloud
3. Anybody else's cloud

**You get the idea!**

Talawa is meant to liberate the management of the operations of multi-organizational communities to provide them with the freedom to choose the best services for their needs.

### Any Server Anywhere

Talawa is designed to be run by any community that wants to manage its membership data on:

1. The physical computer server of their choice or,
2. The virtual machine of their choice or
3. A web hosting provider that may have decided to offer Talawa as a cloud service

The web and mobile app software is designed to:

1. work in `ANY` of these scenarios,
2. be easily configurable by the end user to adjust their operation to communicate with the provider of their choice.

The software is free to be used by anyone, anywhere on any system. 

This allows community based organizations using Talawa to have the flexibility to select the best service provider for all their needs, whether its on their own servers or those of a third party.

### Not Reliant on Palisadoes Services

In the spirit of choice, no aspect of Talawa is reliant on Internet services provided:

1. By the Palisadoes Foundation
2. Through the Palisadoes Foundation

We only provide the code and nothing more.

Nothing in our code base compels community to use any Palisadoes Foundation services.

### Third Party Services

The software may require using other third party providers, but the setup of these services is always under the complete control of the community based organizations not the Palisadoes Foundaion.

### Cloud
It is not intended to be hosted by a single provider where you have no other equivalent service choices like:

1. Facebook
2. Instagram
3. TikTok
4. ChatGPT
5. Netflix

Talawa was created to provide organizations with choices.
